# 프로젝트 작업 규칙

- 현재 작업 폴더의 프로젝트 지침을 따른다. 다른 저장소의 기록이나 설정을 가져오지 않는다.
- 작업을 이어갈 때는 프로젝트 루트의 `HANDOFF.md`에서 `Now`(목표)와 `Next`(다음 행동)를 먼저 읽는다. 지난 기록을 현재 상태로 단정하지 말고, 관련 파일이나 명령 결과와 대조한다.
- 처음 시작하는 프로젝트에 인계가 필요하면 `~/.config/my-ai-memory/templates/HANDOFF.md`를 프로젝트 루트에 `HANDOFF.md`로 복사한다. 이미 있는 인계 문서는 교체하지 않는다.
- 요청한 범위만 변경하고 다른 사람이 수정한 파일을 보존한다. 공개·배포·외부 전송·사용자 데이터 삭제 전에는 해당 행동의 승인을 받는다.
- 작업을 멈추기 전에 실행해서 확인한 결과는 `State`에, 아직 할 일은 `Next`에 적는다. 후속 작업자가 그대로 쓸 파일 경로나 명령을 남기되 비밀번호·토큰·개인정보는 적지 않는다.

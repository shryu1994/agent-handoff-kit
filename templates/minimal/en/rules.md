# Project work rules

- Follow the instructions for the current project. Do not import records or settings from another repository.
- When resuming work, first read `Now` (the goal) and `Next` (the next action) in the project's root `HANDOFF.md`. Check past notes against the relevant files or command output before treating them as current.
- If a new project needs a handoff, copy `~/.config/my-ai-memory/templates/HANDOFF.md` to `HANDOFF.md` at its root. Do not replace an existing handoff.
- Change only what was requested and preserve other people's edits. Get approval for the specific action before publishing, deploying, sending data externally, or deleting user data.
- Before stopping, put verified results in `State` and unfinished work in `Next`. Give the next person a file path or command they can use. Leave out passwords, tokens, and personal information.
